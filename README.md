# Удмурт Кыл

Мобильно-десктопное приложение для обучения детей школьного и дошкольного
возраста удмуртскому языку. Кроссплатформенное: ПК (Windows/Linux/macOS),
Android, iOS.

## Возможности

- **Учить слова** — 10 тем (животные, еда, природа, семья, тело, дом, цвета,
  числа, времена года, школа), более 80 слов с картинками OpenMoji.
- **Картинка и слово** — угадай перевод по картинке.
- **Алфавит** — все 38 букв удмуртского алфавита, включая особые буквы
  (Ӝ, Ӟ, Ӧ, Ӵ, Ӥ).
- **Найди пару** — карточки «картинка–картинка» (дошкольники) или
  «слово–перевод» (школьники).
- **Викторина** — проверь себя.
- **Профиль** — звёзды, пройденные занятия, рекорды и достижения.
- Два режима сложности зависят от роли ребёнка (дошкольник/школьник).

## Технологии

- Java, [libGDX](https://libgdx.com/) 1.12.1
- Gradle 8.10.2
- Картинки — [OpenMoji](https://openmoji.org/) (CC BY-SA 4.0)

## Сборка

Требуется JDK 17+ и Gradle (или используется `gradlew`).

**Десктоп (ПК):**

```
gradlew lwjgl3:dist
```

Готовый jar: `lwjgl3/build/libs/UdmurtLearn-1.0.0.jar`.

**Android (APK):**

Нужен Android SDK (путь к нему указывается в `local.properties`:

`sdk.dir=C\:\\path\\to\\Android\\Sdk`).

```
gradlew android:assembleDebug
```

Готовый APK: `android/build/outputs/apk/debug/android-debug.apk`.

**iOS** — только на macOS (модуль `ios`, RoboVM).

## Авторизация

Аккаунт ребёнка создаётся в самом приложении: логин — ФИО русскими буквами,
пароль хранится в виде SHA-256. Данные сохраняются локально в файле
`udmurt_users.json` (не попадает в репозиторий).
